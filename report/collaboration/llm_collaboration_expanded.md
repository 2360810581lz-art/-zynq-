## 协作职责与工作流

用户提出任务、确认需求、提供物理约束并完成现场摆放与观察；模型阅读源码和报告、提出可证伪假设、生成候选与验证脚本、整理证据并修正结论；确定性工具承担数值比对、仿真、综合和完整性检查。人工物理观察是实物验收的必要输入。

工作流为需求与冻结输入 → 可检查的方案或假设 → 最小实验/报告读取 → 逐项对照 → 反证及修正 → 保存版本与证据 → 提炼模板与负例。此处为单智能体与人工协作流程，未发生多智能体并行调度，不填造节时或准确率收益。

### A02 模型容量预算从总量判断改为同时存活分析

对应完整历史提问未找回；以下依据已保留的旧摘录与工程文件复盘，不编写历史问答。

**任务目标** 早期探索神经网络 HLS 路径，需要判断 xc7z020 的片上资源能否容纳权重和中间特征。原始完整提问缺失，参见旧复盘 C01 与 D02。

**工程观察** 早期模型用“部分特征图也超过 BRAM 总容量”作笼统判断；E19 给出 BRAM 理想容量 645120 字节、INT8 权重 2937564 字节和最大观察特征图 409600 字节。

**自我纠错与决策** 重新计算得到权重约为片上理想容量的 4.55 倍，而最大观察特征图约占 63.5%。应修正为权重不能全部常驻，单张观察特征图可容纳，但必须再计算并存缓冲、系统占用和带宽。

**结果和有效范围** 完成的是容量复核，不能据此声明整个网络可部署。BRAM18/BRAM36 需统一单位，器件和张量位宽改变后重新预算。

**形成的可复用技能** ps-pl-partition。把“经验判断”改为张量字节数、同时存活关系、片上保留量与 DDR 流量四项输入。
