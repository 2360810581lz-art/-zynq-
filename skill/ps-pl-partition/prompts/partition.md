# 从算法描述到软硬件划分

这是本次新提炼的复用模板，并非历史原始提示词。用实际值替换花括号；未知项保留“待测”。

```text
请为 {算法与数据流} 制定PS/PL划分候选。
输入规格：{尺寸、帧率、类型、位宽}；目标器件：{型号、可用LUT/FF/DSP/BRAM}。
现有测量：{各阶段耗时、带宽、资源、样本来源}；已有系统保留：{显示、相机、控制等}。
先输出依赖图，再按生命周期列权重、特征图、行缓存、协议FIFO和DMA缓冲的字节数。
同时给理论容量与可用预算；BRAM18和BRAM36统一单位。共享存储不可重复计数。
逐段说明保留PS或迁移PL的理由，包括随机访存、流式性、回压、控制复杂度和接口代价。
输出表：模块 / 位置 / 输入输出 / 位宽 / 同时存活存储 / 预算来源 / 验证方法 / 待测项。
最后列最小验证候选、黄金参考、无效输入规则和停止条件。
没有实测时不生成FPS或加速比。资源或时序不满足时只提出下一候选，不写为可部署。
```

复核：独立重算一次字节预算；将两个缓冲改为同时存活，检查模型是否调整预算。把网络权重缩小后重新运行，方案应随输入变化，而非总推荐同一硬件架构。
