# 大模型协作记录提示词

本模板为本次提炼，不冒充历史提问。

```text
请仅基于 {真实对话摘录} 与 {原始日志及报告} 整理协作记录。
项目目标：{目标}。输入版本与哈希：{清单}。
请区分原文、复盘总结和新建议；每个结果列证据ID、适用版本与未验证范围。
输出用户目标、模型假设、实际动作、观测、矛盾、自我纠错、验证与迁移边界。
缺失原始提示词时写“未检出，以下为工程复盘”，不要补造问答。
分别记录工具完成、数值等价、HLS估计、实现结果和板测结果。
未找到支持结果的报告时保留待验证，不用对话语气充当验收证据。
```

复核办法：随机抽查至少一个模型数值和一个“通过”结论回到原报告；对存在冲突的旧收据不要覆盖原件，建立新解释记录。
